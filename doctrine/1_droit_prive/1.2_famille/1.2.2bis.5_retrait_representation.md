## Cadre général

L'art. 174 CC est une **MPUC au sens strict**. Il permet au juge, **sur requête** d'un époux, de **retirer en tout ou partie** à l'autre conjoint son **pouvoir de représenter l'union conjugale** (CC 166), lorsque celui-ci :
- **excède** ce pouvoir, ou
- **se montre incapable** de l'exercer.

C'est le **« garde-fou »** de la **responsabilité solidaire** entre conjoints instituée par CC 166 (DESCHENAUX/STEINAUER/BADDELEY N 383 ; CHK-GÖKSU N 1 ; BK-HAUSHEER/REUSSER/GEISER N 5, 11). **Buts** :
- **protéger** le conjoint des conséquences de la solidarité ;
- **éviter de mettre en péril** les intérêts financiers du couple.

L'enjeu pratique est **très limité** dans la société actuelle. CC 174 est rarement utilisé car :
- les **transactions au comptant** et les **paiements électroniques** (cartes de crédit/débit, paiements en ligne) **échappent** à la mesure (ZK-BRÄM N 6 ; BSK ZGB I-ISENRING/KESSLER N 5) ;
- la mesure ne prend effet **qu'avec communication aux tiers** ;
- les époux peuvent en pratique **révoquer une autorisation de représentation extraordinaire** (CC 166 al. 2) sans recours au juge ;
- les **assurances**, les **banques** et autres institutions **filtrent** la solidarité par des clauses contractuelles ;
- les conjoints en désaccord sévère préfèrent généralement la **vie séparée** (CC 175 ss).

## (1) Conditions du retrait

### a) Existence du lien du mariage et d'un ménage commun

**Conditions de l'union conjugale CC 159** doivent être réalisées + **ménage commun** (CPra Actions-BOHNET vol. I § 13 N 2 ; ZK-BRÄM N 7 ; DESCHENAUX/STEINAUER/BADDELEY N 568 ; CHK-GÖKSU N 4 ; BSK ZGB I-ISENRING/KESSLER N 6 ; KuKo ZGB-FANKHAUSER N 3).

**À défaut** : pas de représentation de l'union conjugale → pas de CC 174. **Concubins** : CC 174 inapplicable ; CO 32 ss s'appliquent.

### b) Excès du pouvoir de représentation

**Examen au cas concret** selon la situation familiale et les **besoins courants** (ZK-BRÄM N 10 ; DESCHENAUX/STEINAUER/BADDELEY N 385a ; BK-HAUSHEER/REUSSER/GEISER N 11-12 ; BSK ZGB I-ISENRING/KESSLER N 8 ; CR CC I-RIEBEN/CHAIX N 4).

**Hypothèses** :
- **plusieurs engagements** dépassant les besoins courants (mais pouvant rester dans un cadre acceptable au regard des ressources) ;
- **acte unique** dépassant lourdement les besoins du ménage (ATF 86 II 65 c. 2 ; JdT 1960 I 482 — sous CC 163 al. 2 aCC).

**Reconnaissabilité par les tiers : non déterminante** (DESCHENAUX/STEINAUER/BADDELEY N 385a ; BK-HAUSHEER/REUSSER/GEISER N 10).

**Notion de besoins courants** : voir fiche 1.2.2.8 (CC 166). Besoins **se renouvelant constamment**, **nécessaires à l'entretien usuel et quotidien**, **n'entraînant pas d'entrave particulière au budget**, **dans les habitudes de la famille** + **capacité financière** + **train de vie** + **mœurs et habitudes de la population** (BARRELET, art. 166 N 19 ; OGer BL BJM 1966 74).

### c) Incapacité à représenter l'union conjugale

**Comportement** démontrant que l'époux, pour des raisons de :
- **carences intellectuelles**,
- ou **insuffisance de caractère**,

n'est pas capable de **déterminer et respecter les limites** de son pouvoir (ZK-BRÄM N 21 ; DESCHENAUX/STEINAUER/BADDELEY N 385 ss ; GUILLOD/BURGAT N 625 ; BSK ZGB I-ISENRING/KESSLER N 12a ; CR CC I-RIEBEN/CHAIX N 5 ; CHK-GÖKSU N 6).

**Exemples** :
- époux qui ne respecte pas le budget familial pendant une certaine durée (GUILLOD/BURGAT N 625 ; BSK ZGB I-ISENRING/KESSLER N 12a) ;
- époux qui dépense la totalité du budget mensuel en quelques jours (DESCHENAUX/STEINAUER/BADDELEY N 385b ; CR CC I-RIEBEN/CHAIX N 5).

**Mesure intrusive** → la gestion critiquée doit être **manifestement déraisonnable** (DESCHENAUX/STEINAUER/BADDELEY N 385a ; BK-HAUSHEER/REUSSER/GEISER N 13 ; CR CC I-RIEBEN/CHAIX N 5).

**Pas une cause** : dépenses entrant dans les besoins courants mais dépassant les moyens du couple en raison d'une difficulté de l'autre conjoint.

### d) Risque de répétition du manquement

**Pour l'avenir uniquement** (ZK-BRÄM N 28 ; DESCHENAUX/STEINAUER/BADDELEY N 386 ; BSK ZGB I-ISENRING/KESSLER N 12, 17 ; CR CC I-RIEBEN/CHAIX N 9).

**Risque concret** que la situation se reproduise — **acte unique** ne suffit pas (ZK-BRÄM N 24, 28 ; BSK ZGB I-ISENRING/KESSLER N 12, 16).

**Charge de la preuve** : l'époux demandeur doit **démontrer** que l'abus va se produire ou se répéter (manquements passés, recommandations non respectées, dépenses systématiquement excessives ; ZK-BRÄM N 29).

## (2) Communication aux tiers

### a) Principe — opposabilité

Le retrait **n'est opposable aux tiers que si la mesure leur est connue** (Message mariage 1244 ; ZK-BRÄM N 24 ; CR CC I-RIEBEN/CHAIX N 7, 9). Dès qu'ils en ont connaissance : **immédiatement opposable** (DESCHENAUX/STEINAUER/BADDELEY N 390 ; GUILLOD/BURGAT N 625).

**Bonne foi du tiers** : protégée si méconnaissance non fautive (CC 3 al. 2 ; DESCHENAUX/STEINAUER/BADDELEY N 390 ; BK-HAUSHEER/REUSSER/GEISER N 23).

### b) Avis individuel (al. 2)

**Tiers déterminés et en nombre restreint** : communication **directe par le conjoint requérant** par **avis individuels** (CC 174 al. 2 ; Message mariage 1244 ; ZK-BRÄM N 43 ; DESCHENAUX/STEINAUER/BADDELEY N 390a ; BSK ZGB I-ISENRING/KESSLER N 18 ; CR CC I-RIEBEN/CHAIX N 7).

**Justification** : atteinte moins importante aux droits de la personnalité du conjoint contre lequel la mesure est prononcée (Message mariage 1244 ; CHK-GÖKSU N 8 ; BK-HAUSHEER/REUSSER/GEISER N 19).

**Forme** : libre — **oralement** ou **par écrit** (DESCHENAUX/STEINAUER/BADDELEY N 390 ; BK-HAUSHEER/REUSSER/GEISER N 19 ; CR CC I-RIEBEN/CHAIX N 7).

### c) Publication (al. 3)

**Publication par le juge uniquement** lorsque la communication personnelle n'est pas possible (CC 174 al. 3 ; Message mariage 1244 ; ZK-BRÄM N 44 ; DESCHENAUX/STEINAUER/BADDELEY N 387, 390b ; CHK-GÖKSU N 8 ; BK-HAUSHEER/REUSSER/GEISER N 20 ; BSK ZGB I-ISENRING/KESSLER N 19 ; CR CC I-RIEBEN/CHAIX N 7).

**Support** : pas précisé, mais **feuille officielle** privilégiée (ZK-BRÄM N 44 ; BK-HAUSHEER/REUSSER/GEISER N 20 ; BSK ZGB I-ISENRING/KESSLER N 19 ; CR CC I-RIEBEN/CHAIX N 7).

**Atteinte importante à la personnalité** → le juge doit faire preuve de **retenue** + **proportionnalité** + **pesée des intérêts**. Publication seulement si **nécessaire et utile** ; ne pas envisager si moyen moins contraignant possible (ZK-BRÄM N 44 ; CHK-GÖKSU N 8 ; BSK ZGB I-ISENRING/KESSLER N 19).

**Effet** : les tiers **sont considérés** avoir pris connaissance de la mesure (GUILLOD/BURGAT N 625 ; DESCHENAUX/STEINAUER/BADDELEY N 390 ; CHK-GÖKSU N 8 ; BK-HAUSHEER/REUSSER/GEISER N 23 ; CR CC I-RIEBEN/CHAIX N 9).

## (3) Portée

### a) Exercice des droits civils

**Seul un conjoint ayant l'exercice des droits civils** peut représenter l'union et donc se voir retirer le pouvoir (ZK-BRÄM N 18 ; DESCHENAUX/STEINAUER/BADDELEY N 330, 385b ; CHK-GÖKSU N 6).

**Droit strictement personnel et intransmissible** → le **représentant légal** ne peut pas exercer le pouvoir (CC 166 N 9 ; ZK-BRÄM N 19 ; CHK-GÖKSU N 6).

**Pour les époux privés des droits civils** : application du droit de la **protection de l'adulte** (ZK-BRÄM N 20).

**Délimitation** entre **incapacité générale** (CC 19) et abus du pouvoir : pas toujours aisée (ZK-BRÄM N 21). L'incapacité CC 174 relève d'un **problème personnel** ou de **difficultés conjugales** (achats compulsifs, ego déficient, etc. — ZK-BRÄM N 21).

### b) Application au pouvoir extraordinaire de représentation — controverse

**CC 166 al. 2 ch. 1** (autorisation expresse) ou **CC 166 al. 2 ch. 2** (urgence) : application de CC 174 **controversée** (ZK-BRÄM N 15 ; DESCHENAUX/STEINAUER/BADDELEY N 384a ; KuKo ZGB-FANKHAUSER N 2 ; CHK-GÖKSU N 5 ; BSK ZGB I-ISENRING/KESSLER N 9 ; CR CC I-RIEBEN/CHAIX N 2 ; OFK ZGB-SCHMID N 2).

**Sans grande influence pratique** (ZK-BRÄM N 25) :
- **Autorisation par le conjoint** : **révocable en tout temps** (CO 34 al. 1) → intervention du juge **inutile** ; requête sans intérêt (CPC 59 al. 2 lit. a).
- **Autorisation par le juge** (CC 166 al. 2 ch. 1) : retrait possible si l'acte n'est pas accompli + **circonstances nouvelles** depuis l'autorisation (ZK-BRÄM N 15 ; comp. BSK ZGB I-ISENRING/KESSLER N 10) ; alternativement, application de CC 179 (modification — ZK-BRÄM N 16).
- **Situation de nécessité** (CC 166 al. 2 ch. 2) : **disparaît dès que l'urgence tombe** ; intervention du juge **inutile** (ZK-BRÄM N 17, 33 ; CHK-GÖKSU N 5 ; BSK ZGB I-ISENRING/KESSLER N 11).

**Application par anticipation** envisagée par certains pour empêcher la représentation en urgence — **caractère boiteux** reconnu (ZK-BRÄM N 34 ; DESCHENAUX/STEINAUER/BADDELEY N 383a).

**Conclusion** : application théoriquement envisageable mais **extrêmement difficile, voire impossible** en pratique (ZK-BRÄM N 26, 31 ; CHK-GÖKSU N 5).

### c) Autres droits non concernés

**Pas concerné** :
- pouvoirs CC 227 (communauté de biens) ;
- copropriété (CC 646 ss) ;
- société simple (CO 543 al. 2).

(DESCHENAUX/STEINAUER/BADDELEY N 384d ; KuKo ZGB-FANKHAUSER N 2 ; CHK-GÖKSU N 3 ; BK-HAUSHEER/REUSSER/GEISER N 7a ; BSK ZGB I-ISENRING/KESSLER N 4 ; CR CC I-RIEBEN/CHAIX N 2).

### d) Transactions au comptant et paiements électroniques

**Hors champ** :
- **transactions en cash** ;
- **argent virtuel** (cartes de crédit/débit, paiements internet).

(ZK-BRÄM N 6 ; BSK ZGB I-ISENRING/KESSLER N 5 ; CHK-GÖKSU N 2).

**Logique** : les époux sont solidaires en cas de paiement électronique car ils se lient **contractuellement** en s'autorisant mutuellement à utiliser leurs cartes/comptes. **Lien contractuel** rompable **sans intervention du juge** (ZK-BRÄM N 6).

**Conséquence pratique** : **portée résiduelle** de CC 174 dans la société actuelle (ZK-BRÄM N 6).

## (4) Procédure

### a) Action et compétence

**Mesure formatrice** ; **action du juge MPUC** (CPC 271 N 3 et fiche procédure dédiée). **Cumul possible** avec action condamnatoire ou en constat (CPC 87 ; CPC-BOHNET art. 87 N 22). **Procédure sommaire** (CPC 271 lit. a).

**Pas d'office** : seulement à la **demande d'un conjoint** (CC 172 al. 3 ; ZK-BRÄM N 23 ; DESCHENAUX/STEINAUER/BADDELEY N 388 ; CHK-GÖKSU N 7 ; BSK ZGB I-ISENRING/KESSLER N 15 ; CR CC I-RIEBEN/CHAIX N 6).

### b) Tentative de conciliation

**Précédée d'une tentative de conciliation** (CC 172 al. 2 ; DESCHENAUX/STEINAUER/BADDELEY N 388).

### c) Charge de la preuve

L'époux demandeur **démontre** que les conditions du retrait sont remplies (ZK-BRÄM N 23 ; GUILLOD/BURGAT N 625). **Degré de preuve** : **simple vraisemblance** (CPC 273 N 28).

### d) Proportionnalité — pesée

Mesure intrusive → **proportionnalité** stricte (DESCHENAUX/STEINAUER/BADDELEY N 386 ; GUILLOD/BURGAT N 625 ; BK-HAUSHEER/REUSSER/GEISER N 15a ; ZK-BRÄM N 24 ; BSK ZGB I-ISENRING/KESSLER N 16).

Le juge doit :
- s'assurer que le conjoint va **certainement** abuser du pouvoir (ZK-BRÄM N 24) ;
- **privilégier des mesures moins restrictives** (admonestation, retrait partiel, consultation budgétaire CC 171 — ZK-BRÄM N 24a ; BSK ZGB I-ISENRING/KESSLER N 16 ; CR CC I-RIEBEN/CHAIX N 6).

### e) Retrait partiel ou général

Le juge **vérifie d'abord** s'il est possible de **limiter la privation** :
- à un **certain type d'actes** ;
- ou à un **certain montant** ;

(ZK-BRÄM N 29 ; DESCHENAUX/STEINAUER/BADDELEY N 386 ; CHK-GÖKSU N 7 ; BK-HAUSHEER/REUSSER/GEISER N 15a, 19).

**Retrait général** : seulement si la limitation n'est pas possible.

### f) Mesures provisionnelles / superprovisionnelles

**Possible en cas d'urgence** (CPC 261 ss ; CPC 265 — Message mariage 1244 ; CR CC I-RIEBEN/CHAIX N 6 ; DESCHENAUX/STEINAUER/BADDELEY N 388 ; BK-HAUSHEER/REUSSER/GEISER N 15-16).

### g) Modification

**CC 179** : si les circonstances changent, modification possible sur requête (Message mariage 1244 ; DESCHENAUX/STEINAUER/BADDELEY N 392 ; GUILLOD/BURGAT N 625 ; CR CC I-RIEBEN/CHAIX N 10). Voir fiche 1.2.2bis.13.

### h) Effet suspensif d'appel

**Pas d'effet suspensif** d'appel (CPC 315 al. 2 lit. b — applicable aux MPUC). Selon JEANDIN, *Voies de droit (CPC 2025)* N 30, 31 : exclut l'application de CPC 315 al. 3.

## (5) Effets

### a) Effet sur la solidarité

L'époux touché peut **continuer à s'engager à titre personnel**. Le retrait fait **cesser la responsabilité solidaire** de son conjoint (CC 166 al. 1 ; ZK-BRÄM N 37 ; DESCHENAUX/STEINAUER/BADDELEY N 389 ; CHK-GÖKSU N 7 ; BK-HAUSHEER/REUSSER/GEISER N 22 ; BSK ZGB I-ISENRING/KESSLER N 20 ; CR CC I-RIEBEN/CHAIX N 8).

**L'époux concerné n'est pas incapable** au sens de CC 19 al. 1 (CHK-GÖKSU N 6).

### b) Séparation et reprise

**Séparation** : les époux **ne se représentent plus** (CC 166) → **mesure CC 174 perd ses effets** (ZK-BRÄM N 7 ; CR CC I-RIEBEN/CHAIX N 10).

**Reprise de la vie commune** : la décision **reprend immédiatement ses effets** (ZK-BRÄM N 7).

### c) Régime matrimonial

Le sort de la dette engendrée par l'époux **dépend du régime matrimonial** (ZK-BRÄM N 37 ; DESCHENAUX/STEINAUER/BADDELEY N 389 n. 215 ; BK-HAUSHEER/REUSSER/GEISER N 23 ; BSK ZGB I-ISENRING/KESSLER N 24a ; CR CC I-RIEBEN/CHAIX N 8).

### d) Bonne foi du tiers — limites

**Tiers protégé** dans sa bonne foi tant que la mesure ne lui est pas connue. **Circonstances poussant à croire** que le conjoint représente l'union (notamment vie commune apparente) → tiers **légitimé à faire appel à la solidarité** de l'autre époux (ZK-BRÄM N 38, 39 ; BSK ZGB I-ISENRING/KESSLER N 21, 23). **Recours interne** ensuite contre l'époux fautif (ZK-BRÄM N 37 ; BSK ZGB I-ISENRING/KESSLER N 21 ; CR CC I-RIEBEN/CHAIX N 9).

**Tiers informé / publication faite** : **bonne foi exclue**, même s'il n'a pas eu connaissance effective de la publication (ZK-BRÄM N 40 ; CHK-GÖKSU N 8 ; BK-HAUSHEER/REUSSER/GEISER N 23 ; CR CC I-RIEBEN/CHAIX N 9). **Acte demeure valable** mais **ne déploie pas d'effets** pour l'époux protégé (ZK-BRÄM N 41 ; BSK ZGB I-ISENRING/KESSLER N 24).

## Aspects DIPr

Section inhérente. Renvoi à **1.2.2.12** et **1.2.2bis.17**.

1. **Compétence** : LDIP 46 (domicile suisse) — autorité MPUC compétente.
2. **Loi applicable** : LDIP 48 — droit suisse en cas de domicile commun en Suisse.
3. **Représentation à l'étranger** : si les actes touchent un tiers étranger, application des règles CO 32 ss + droit étranger éventuel pour la protection du tiers de bonne foi.
4. **Publication transfrontalière** : pas de mécanisme — possible nécessité d'avis individuels aux tiers étrangers connus.

## Évolution du droit

- **1.1.1988** : LF 5.10.1984 — entrée en vigueur de CC 174 dans sa structure actuelle (ancien régime patriarcal supprimé).
- **1.1.2011** : entrée en vigueur du CPC ; procédure sommaire CPC 271 lit. a applicable.
- **2025** : révision CPC — pas d'incidence majeure sur CC 174 mais voies de droit (JEANDIN).
- **1.7.2022** : mariage pour tous ; CC 174 applicable identiquement.

## Pièges courants

1. **Champ très restreint** : ne touche pas le cash, les cartes, les paiements électroniques.
2. **Concubins** : exclus ; CO 32 ss s'appliquent.
3. **Ménage commun** requis ; séparation = perte d'effet automatique.
4. **Risque de répétition** : condition impérative ; pas un acte unique sauf si lourd.
5. **Pour l'avenir uniquement** : pas de rétroactivité.
6. **Manifestement déraisonnable** pour l'incapacité.
7. **Avis individuel** à privilégier sur la publication (atteinte à la personnalité).
8. **Publication** : feuille officielle ; uniquement par le juge ; proportionnalité stricte.
9. **Application au pouvoir extraordinaire** : controversée et inutile en pratique.
10. **CO 34 al. 1** : autorisation extraordinaire **révocable** sans recours au juge.
11. **Société simple, copropriété, communauté** : régies par leurs règles propres.
12. **Cumul d'actions** possible (CPC 87).
13. **Vraisemblance** suffisante (CPC 273 N 28).
14. **Retrait partiel** à privilégier (proportionnalité).
15. **Modification CC 179** possible.
16. **Mesures provisionnelles** : possibles en urgence (CPC 261 ss).
17. **Pas d'effet suspensif d'appel** (CPC 315 al. 2 lit. b).
18. **Bonne foi des tiers** : protégée tant qu'ils ignorent la mesure.
19. **Régime matrimonial** : impact sur la dette résiduelle.
20. **Reprise de la vie commune** : la mesure reprend ses effets immédiatement.
